# Архив прежнего процесса спецификаций

Этот каталог содержит исторические артефакты прежнего workflow. Он сохранён
для аудита и отката и не является источником новых требований, задач или
изменений.

Активный процесс Gurra:

- Spec Kitty владеет mission, требованиями, планом, рабочими пакетами и
  статусом;
- Beads владеет issue identity, приоритетом и графом зависимостей;
- live-конфигурация, restart и rollout остаются отдельным явным gate.

Новые файлы в этот каталог не добавлять. Историю не переписывать и не
удалять без отдельного подтверждения.
