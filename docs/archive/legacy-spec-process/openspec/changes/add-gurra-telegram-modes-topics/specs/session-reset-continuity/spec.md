## ADDED Requirements

### Requirement: Точное сообщение reset
При автоматическом reset система MUST сообщать, что очищен активный контекст, а прежняя сессия сохранена и может быть восстановлена через `/resume`; сообщение MUST NOT утверждать, что вся история удалена.

#### Scenario: Автоматический reset
- **WHEN** настроенная reset policy запускает reset активной сессии
- **THEN** пользователь получает сообщение об очищенном контексте и сохранённой resumable-сессии

### Requirement: `/new` сохраняет архив и topic preferences
Команда `/new` MUST завершать текущий активный контекст как доступную для `/resume` сессию, создавать новый контекст, сохранять topic model/reasoning preferences и сбрасывать session-scoped Fast API.

#### Scenario: Возврат к прежней сессии
- **WHEN** после `/new` пользователь открывает `/sessions` и восстанавливает разрешённую прежнюю сессию
- **THEN** её transcript доступен в соответствии с существующими правилами авторизации
